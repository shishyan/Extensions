🔒 Zero-Telemetry Privacy Policy

Effective Date: November 1, 2026

All browser extensions published under the Influenzian Extensions Suite (including TubeIQ Max, GrammFix, MerlCopilot, HuntLead, SurfSEO, KeepPrice, DarkZen, SnapBug, DashVault, and MassMail) operate on a strict 100% Client-Side, Zero-Telemetry architecture:

  • No Personal Data Collection: We do not collect, log, store, sell, or transmit your browsing history, personal identifiers, credentials, or usage analytics to any external server owned by us.
  • Local Storage Only: User settings, watchlists, snippets, and encrypted vault entries are stored strictly inside your local browser profile via chrome.storage.local.
  • Direct Public API Queries Only: When an extension queries public autocomplete (e.g., YouTube/Google suggestions), grammar checking (LanguageTool public endpoint), or k-Anonymity breach ranges (first 5 hex characters of a SHA-1 hash via HaveIBeenPwned), the request goes directly from your browser to that public endpoint with zero intermediate proxy.
