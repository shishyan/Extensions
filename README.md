## ⚡ Quick Installation

### Google Chrome / Microsoft Edge / Brave
1. Download any **`<slug>-chrome-edge.zip`** from [Releases (`v1.0.0`)](https://gitlab.com/influenzian-group/Extensions/-/releases/v1.0.0) (or clone this repo).
2. Open `chrome://extensions` (or `edge://extensions`) and enable **Developer mode** (top-right toggle).
3. Drag-and-drop the `.zip` (or click **Load unpacked** and select `<slug>/`).

### Mozilla Firefox
1. Download any **`<slug>-firefox.zip`** from [Releases (`v1.0.0`)](https://gitlab.com/influenzian-group/Extensions/-/releases/v1.0.0).
2. Open `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on...** (or install via Firefox Developer/Nightly).
